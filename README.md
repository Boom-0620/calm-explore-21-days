# 平静地探寻

> 一个孩子的 21 天。一场关于"感知"的互动探索。

灰色纸面上有一团黑色的乱线。
一个孩子在 21 天里一点一点把它拆开——
线慢慢变成：形状、物体、颜色、光、震动、触感、气味、味道、风、空间、记忆、世界。

到最后才发现：我们以为自己在寻找世界，其实是在寻找**认识世界的方法**。

## 怎么玩

**双击打开 `index.html` 即可**（单文件作品，无需安装、无需联网）。

- 每一天都是一个小故事，但**没有操作说明**——
  线会自己轻轻动一下，太阳会暖暖地亮着：碰一碰、拖一拖、按住不放、画一笔试试。
- 你摸过的东西会留下痕迹：摸过的太阳在后来的世界里是亮的，
  找到过的气味会变成彩色的线，走过的光会铺成路。
  所以第 20 天的"记忆地图"，每个人都不一样。
- 进度会自动保存在浏览器里，明天可以从"昨天的日记"继续。

## 21 天

| 阶段 | 天数 | 内容 |
|---|---|---|
| 混沌 | Day 01–03 | 灰色、黑色乱线、一根线、一个圆 |
| 形状 | Day 04–05 | 圆、三角、方、小人、边界 |
| 颜色 | Day 06–07 | 第一个红色、暖暖的太阳 |
| 感知 | Day 08–12 | 震动、触摸、气味、味道、万物的名字 |
| 连接 | Day 13–14 | 万物皆由线变、五种感觉 |
| 世界 | Day 15–17 | 光的路、车的震动、风 |
| 豆豆 | Day 18–20 | 那个小东西、一模一样的线、抓住它 |
| 是我 | Day 21 | 镜子、小路、"我还要去看看。" |

## 技术

纯原生 JavaScript + Canvas 单文件实现：蜡笔质感线条引擎（多段抖动、双笔触、纸张噪点）、
逐字随机排版的"儿童字迹"渲染器、localStorage 探索痕迹存档。无框架、无依赖、无网络请求。
